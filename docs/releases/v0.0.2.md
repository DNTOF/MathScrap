# MathScrap 0.0.2（草稿 / draft）

这份说明是发布草稿。合并、打标签和发布都还没有做。

This is a draft. Nothing has been merged, tagged, or published yet.

## 笔迹手感原型（默认关闭）

新增 `src/ink/`：平滑（去近点 + 中点贝塞尔）、预测尾迹（可选浅色）、扫掠胶囊橡皮、按指针类型的容差、湿墨增量重绘，以及 `?ink-debug=1` 调试面板。所有开关默认关闭；关闭时纸面行为与 0.0.1 相同。数据来自合成轨迹回放，还没有真机笔迹或 iPad 实测结论。

## iOS 未签名 IPA

新增 `MathScrap-0.0.2-ios-unsigned.ipa`。它没有苹果签名和描述文件，只能用 TrollStore 或在已越狱的设备上安装；普通 iOS 会拒绝。构建机上有 `ldid` 时，包里带一个 ad-hoc 伪签名，只用来保留 entitlements。最低 iOS 15.0，设备切片是纯 arm64（A8X 起，例如 iPadOS 15 的 iPad Air 2）。iPadOS 15 上笔迹和数学引擎可用。手写识别依赖的 onnxruntime-web 只有 WebAssembly SIMD 版本，而 WebKit 从 iOS 16.4 才支持 SIMD，所以在 iPadOS 15 上点「识别」会提示不可用，不会下载模型或崩溃；这一点和 16.4 以上设备上的识别都还没有真机验证。iOS 和 Android 不启动本机 MCP 监听。

## 圆角图标

Windows、macOS、Linux 和网页图标改为由 `packaging/logo/app-icon.png` 生成的圆角版本（`packaging/logo/app-icon-rounded.png`，四角透明）。iOS 继续用不透明的方形原图，由系统裁成圆角；预先做透明圆角会被裁两次或露出黑角。Android 保留自适应图标和圆形图标。

## 按改动范围跑 CI

`package` 工作流先分类改动：只改文档的 PR 只跑一致性检查（版本号、分类器回归、打包脚本语法、工作流 YAML）；只改版本字段同样不跑数学测试，但推到 main 时照常打包；只改打包脚本或图标时实际构建安装包而不跑数学测试；混合或无法归类的改动跑全量。新增文档文件（例如 `CONTRIBUTING.md`）不再触发全量。`ci-ok` 是唯一需要设为必需的状态。打包任务额外生成一份覆盖 Android、Windows 和 iOS 的 `SHA256SUMS`。

## 核对

在自己的电脑上计算 SHA-256，与发布页的 `SHA256SUMS` 比较。Windows 和 Android 的签名方式与 0.0.1 相同（见 `signing/v0.0.1/` 和 `docs/release-check.md`）。iOS 包未签名。

## Ink-feel prototype (off by default)

Adds `src/ink/`: smoothing (near-point drop + midpoint Bezier), a predicted tail (optionally a translucent ghost), a swept capsule eraser, per-pointer-type tolerance, incremental wet-ink redraw, and a `?ink-debug=1` panel. Every flag is off by default; with them off the sheet behaves as in 0.0.1. The numbers come from synthetic trace replay, not from real handwriting or an iPad.

## Unsigned iOS IPA

Adds `MathScrap-0.0.2-ios-unsigned.ipa`. It has no Apple signature and no provisioning profile and installs only through TrollStore or on a jailbroken device; stock iOS refuses it. When `ldid` is on the builder, the app carries an ad-hoc fake signature that only preserves entitlements. Minimum iOS 15.0 with a plain arm64 device slice (A8X and later, for example an iPad Air 2 on iPadOS 15). On iPadOS 15, ink and the math engine work. Handwriting recognition uses onnxruntime-web, which ships only WebAssembly SIMD builds, and WebKit has SIMD only from iOS 16.4, so on iPadOS 15 Recognize reports that recognition is unavailable instead of downloading the models or crashing. Neither that path nor recognition on 16.4+ has been verified on a device. iOS and Android do not start the local MCP listener.

## Rounded icon

Windows, macOS, Linux and the web favicon now use a rounded-corner icon generated from `packaging/logo/app-icon.png` (`packaging/logo/app-icon-rounded.png`, transparent corners). iOS keeps the opaque square master and applies its own mask; baked transparent corners would be masked twice or show black corners. Android keeps its adaptive and round launcher icons.

## Change-aware CI

The `package` workflow classifies each change first. Docs-only PRs run only consistency checks (versions, classifier regression, packaging script syntax, workflow YAML). Version-only changes also skip the math suite but still package on push to main. Packaging-only changes build the packages instead of running the math suite. Mixed or unclassified changes run the full suite. Adding a docs file such as `CONTRIBUTING.md` no longer forces the full suite. `ci-ok` is the single status to require. The packaging run also writes one `SHA256SUMS` across Android, Windows and iOS.

## Verify

Hash the files on your own computer and compare with `SHA256SUMS` on the release page. Windows and Android signing follow 0.0.1 (see `signing/v0.0.1/` and `docs/release-check.md`). The iOS package is unsigned.
